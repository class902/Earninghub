# Calculator

A lightweight, responsive calculator web app.

## Features
- Basic arithmetic: addition, subtraction, multiplication, and division
- Keyboard support
- Responsive layout for mobile and desktop
- Deployable as a static website with GitHub Pages

## Hosting
In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)` (or configure the root landing page to point to this app), then save.

The calculator app source will be added in this directory.
